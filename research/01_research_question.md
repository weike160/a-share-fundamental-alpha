## 1. 核心研究问题

> **A 股市场在财报信息公布后，是否存在持续性的价格反应？这种现象在消除未来函数（look-ahead bias）、幸存者偏差（survivorship bias），并加入真实交易约束之后，是否仍然存在？**

这个问题的两层含义：

1. **是否存在** —— 财报信息是否真的没有被市场一次性计价，而是留下可预测的漂移？
2. **在真实约束下是否仍然存在** —— 即使观察到了漂移，它是否大到足以覆盖交易成本、且能够在 stock pool 的流动性范围内执行？

## 2. 为什么这是一个值得研究的问题（Economic Motivation）

PEAD（Post-Earnings Announcement Drift）是金融学研究中被反复验证过的现象，它揭示了 **市场对信息并非即时完全反应** 的机制。研究它的价值在于它同时是：

- 一个经典的 **Anomaly / Alpha 候选**；
- 一扇窥见市场 **信息吸收机制** 的窗口；
- 一个天然适合用来展示「严谨的量化研究流程」的载体。

更重要的是，A 股与美股在制度上有显著差异（涨跌停、T+1、融券受限、散户占比高、公告时点不统一），因此 **美股上的 PEAD 结论不能直接搬运**。这正是这个项目存在的意义：把教科书上的 anomaly 放到 A 股真实的制度、数据与摩擦之下重新检验。

## 3. 核心假设

### 3.1 主假设

```
SUE ↑  ⇒  FutureReturn ↑
```

即：财报表现越超预期，公告后的股票在未来若干交易日是否继续表现更好？

### 3.2 形式化定义

以 earnings surprise 为中心：

```
SUE_{i,t} = (ActualEPS_{i,t} − ExpectedEPS_{i,t}) / σ(EarningsSurprise_{i})
```

待检验的关系：

```
corr( SUE_{i,t}, Return_{i,t+1:t+T} )  >  0 ,  对 T ∈ {1,5,10,20,40,60}
```

### 3.3 预期与数据约束

- **信息必须在公告真正公开之后才进入模型**：`InformationTime < TradingTime`。
- **ActualEPS 与 ExpectedEPS 须同时、同口径可得**，否则会出现变量错配。
- 若无分析师一致预期数据，可用**替代指标**（见 §5），但要明确替换的局限。

## 4. 信号候选（Phase-1 先用简单、可解释的）

| 信号 | 含义 | 数据依赖 | 优先级 |
|---|---|---|---|
| **SUE** | 标准化未预期盈余 | 实际 EPS + 预期 EPS | ⭐ 核心 |
| 净利润同比 | 净利润 YoY | 财报 | 替代 |
| 营收同比 | 营收 YoY | 财报 | 替代 |
| EPS 同比 | EPS YoY | 财报 | 替代 |
| ROE 变化 | ROE 同比变化 | 财报 | 辅助 |
| 毛利率变化 | 毛利率同比变化 | 财报 | 辅助 |
| 业绩预告超预期 proxy | 预告 vs 公告 | 业绩预告 | 辅助 |

> **Phase-1 决策**：优先用 **SUE**（若分析师数据可得）；否则退化为**净利润/营收同比**作为早期替代，并在报告的局限性里明确说明。

## 5. 需要回答的子问题

1. PEAD 是否存在于 A 股？（主假设检验）
2. 这种漂移能持续多久？（IC Decay：1/5/10/20/40/60 天）
3. 信号在控制行业、市值、动量、波动率之后是否仍然显著？（横截面回归 β₁(SUE)）
4. Alpha 是否在特定维度上更强？（市值 / 流动性 / 波动率 / 分析师覆盖 —— 机制分析）
5. 在加入佣金、印花税、滑点、冲击成本后，净 Alpha 还剩多少？（交易成本）
6. 机器学习（LightGBM / MLP）是否在简单因子之上产生稳定增量？（ML 扩展）

## 6. 度量指标（判定信号是否「真的有价值」）

研究层面的**初级判据**（对应验收 Level 2）：

- **RankIC**（跨期均值）
- **ICIR** = Mean(IC) / Std(IC)
- **Q1–Q10 分层收益的单调性**
- **中性化后 β₁(SUE) 的显著性**（行业 + 市值 + 动量 + 波动率）

研究层面的**高级判据**（对应验收 Level 3/4）：

- **Net Sharpe / MaxDD / Turnover / TrackingError / IR**
- **Gross → Net Alpha 的衰减比例**
- **Capacity**（基于 ADV 的可执行规模）
- ML 的 **out-of-sample RankIC / Net Sharpe** 是否高于 Linear baseline

## 7. 什么情况下「这个假设不成立 / 不值得继续」

明确写出来作为**证伪条件**，避免后期自欺：

- 若 RankIC ≤ 0 且不显著 ⇒ 假设不成立，**停止**，换研究方向或换 signal。
- 若 RankIC 显著为正，但**中性化后 β₁(SUE) 不显著** ⇒ 现象可能是风格暴露的伪影，**不能成立为独立 Alpha**。
- 若 **Gross Alpha 可观但扣除交易成本后 ≈ 0** ⇒ 策略在当前假设下**不可交易**，需重新评估信号频率 / 持有期 / 股票池。
- 若结果**完全依赖某一组参数或某一样本期** ⇒ 高度疑似**过拟合**，结果不可信。
